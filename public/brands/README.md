# Model brand marks

These original assets are stored locally to identify the models in the How it works panel.

- `jev-typesafe.png`: TypeSafe's publisher mark, used for Jev. Source: [TypeSafe documentation](https://docs.typesafe.ai/models), which references [this icon](https://docs.typesafe.ai/mintlify-assets/_mintlify/favicons/ts-docs/zg2v0DiYB7xPw0I2/_generated/favicon/android-chrome-192x192.png).
- `deepseek.svg`: DeepSeek's whale mark. Source: [DeepSeek API documentation](https://api-docs.deepseek.com/), which references [this SVG](https://api-docs.deepseek.com/img/favicon.svg).

Both files were copied unchanged. The marks belong to their respective owners; this project does not grant rights to them.
